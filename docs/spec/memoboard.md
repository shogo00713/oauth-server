# メモボード

## 概要
- シンプルメモアプリを拡張して、使いやすくしたアプリ
- OAuth の client として働き、Web UI から管理する
- 存在意義は薄い気もするけど、まあいいでしょ

## 機能
- メモ一覧
- メモの作成、編集、削除
- キーワード検索

## 画面
| パス | メソッド | 役割 |
|---|---|---|
| `/` | GET | メモ一覧|
| `/detail/:id` | GET、POST | メモの表示、編集、削除 |
| `/login` | GET | 認可リクエストを始める |
| `/callback` | GET | `redirect_uri` |
| `/logout` | POST | ログアウト |


## データモデル
- 初期段階では、アカウントを持たず、認可サーバーでシンプルメモアプリにログインした情報で出し分けをする形
