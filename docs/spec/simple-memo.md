# シンプルメモアプリ

## 概要
- 簡単なメモアプリ
- OAuth の RS として働き、API を提供する
- 便宜上 API メインの利用となるが、のちにこのアプリ自体でも Web UI で操作できるようにする

## データモデル
-　各ユーザーが1つのアカウントを持ち、アカウントには複数のメモを持てる
- 各アカウントには、ユーザーID, ユーザー名, パスワードハッシュ を持つ
- 各メモには、メモID, 持ち主ユーザーID, 本文, 作成日時, 更新日時 を持つ

## API 

| パス | メソッド | 受理する scope | 内容 |
|---|---|---|---|
| `/memos` | GET | `read` または `write` | 一覧画面 |
| `/memos/:id` | GET | `read` または `write` | 個別のメモの画面 |
| `/memos` | POST | `write` | 新しいメモの作成 |
| `/memos/:id` | PUT | `write` | メモの更新 |
| `/memos/:id` | DELETE | `write` | メモの削除 |

## 認可ルール

### スコープ
次の2つのスコープを持つ
1. read : GET のみ可能
2. write : read に加えて、POST,PUT,DELETE も可能
